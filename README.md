# Chess Game

A professional desktop chess game with Stockfish AI integration and rich features.

## Features
- Full chess engine with all rules (castling, en passant, pawn promotion)
- Beautiful PyQt6 GUI with drag-and-drop moves
- Arrow drawing system (chess.com style)
- Premove system
- Stockfish AI with 5 difficulty levels (300-2000 Elo)
- Real-time evaluation bar
- Settings panel
- Save/load games (PGN format)
